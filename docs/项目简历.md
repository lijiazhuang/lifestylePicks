# 生活优选（LifestylePicks）｜Java 后端开发

**项目描述：** 面向店铺点评与优惠券秒杀的本地生活服务平台，支持验证码登录、店铺检索、附近店铺查询、探店笔记、关注推送、点赞评论及优惠券秒杀。基于原单体项目完成微服务改造，按业务领域拆分用户、店铺、内容和交易服务，统一接入网关。

**技术栈：** Spring Boot、Spring Cloud Gateway、MyBatis-Plus、MySQL、Redis、Lua、Redisson、RocketMQ、RestTemplate、Maven、Nginx。

**主要工作：**

1. **微服务架构改造：** 按业务边界拆分四个可独立启动的服务，搭建 Maven 父工程统一管理依赖；抽取 common 与 api 模块，集中维护用户上下文、调用接口及共享 DTO，保持原前端接口兼容。
2. **统一认证与身份传递：** 在网关设计两层全局过滤器，分别实现 Redis Token 登录态恢复与续期、按请求方法和路径进行登录校验；清除客户端伪造身份头，将可信 userId 传递下游，通过自动装配的 MVC 拦截器维护并清理 UserContext。
3. **秒杀并发与异步下单：** 使用 Redis Lua 原子校验活动时间、库存与重复购买，并完成库存预扣；通过 RocketMQ 异步保存订单、扣减数据库库存，结合 Redisson 分布式锁、已有订单校验及本地事务，实现重复消息幂等处理与失败回滚。
4. **可靠投递与状态管理：** 将库存预扣和待投递记录在 Lua 中原子写入，利用 Redis ZSET 与定时任务补发未确认消息；区分消息发送确认与订单落库结果，维护 PENDING/SUCCESS/FAILED 状态，支持消费异常重试和订单归属查询。
5. **缓存及 Redis 业务应用：** 使用 Cache Aside 与事务提交后缓存失效处理店铺更新，缓存空值缓解缓存穿透；利用 Redis GEO 实现附近店铺距离排序与分页，Bitmap 实现签到，ZSET 实现点赞用户排序和 Feed 滚动查询。
6. **服务通信与验证：** 将用户资料远程调用统一封装到 api 模块，支持批量分片、超时配置及可信身份传递，减少逐条作者查询带来的远程调用；通过单元测试和独立 MySQL/Redis 联调验证业务拆分，并使用模拟 MQ 客户端覆盖发送未确认、重复消费和数据库失败回滚场景。

## 描述边界

- 登录使用 Redis Token，当前没有 JWT。
- RocketMQ 使用普通消息与待投递补发，当前没有事务消息回查。
- 死信处理与自动库存释放闭环目前仅讨论过设计，没有实现。
- MQ 相关逻辑通过模拟客户端验证，没有完成虚拟机 Broker 联调。
- 服务可独立启动，默认暂时复用原数据库；没有对现有数据库执行物理迁库。
- 未进行压测，因此不填写 QPS、吞吐量或性能提升百分比。
